# Interface constraints

The competition follows the supplied Code Connect 26 / Bug Hunt 2026 Advanced event artwork: charcoal surfaces, off-white text, solid red accents, square edges, ruled rows, and text controls. Impact / Arial Narrow headings and Arial body text use system fonts. Round navigation uses a stacked list; operational statistics use plain figures.

The five supplied WhatsApp event graphics identify University of Karachi, UBIT Career Connect 26, and Code Connect 26. The first graphic is retained unchanged in `frontend/public/branding/code-connect-event.jpeg`; a fixed, responsive CSS viewport displays only its original organizer logo row. The logo row appears throughout the platform and on verified certificates. Poster glow effects, decorative code screens, and practical-activity copy are not incorporated into the interface. All four official rounds retain written/code-review submissions; Document B remains excluded. Branding does not change competition content, timing, scoring, permissions, or authentication.

No gradients, neon or pastel palettes, pure-white page backgrounds, drop shadows, rounded panels, decorative glass, radial orbs, dot grids, bento feature layouts, terminal-window decoration, emojis, decorative checkmarks, sparkle symbols, animated arrows, hover animations, or Lucide icons appear in the product interface. Functional code review remains readable in plain code blocks. Native form controls remain accessible.

There are no invented prices, testimonials, or product claims. The account walkthrough opens actual account controls and live Mission Control; it creates no sample teams, scores, or practice activities. Static loading placeholders have a readable status and no animation. Terms of use and a privacy notice describe the existing competition behavior and the current retention uncertainty.

Unconnected starter UI components and dependencies remain available in the source checkout; they are not imported into the competition interface. New product changes must keep these constraints.
